# Quick Bytes

Concise technical references, system design guides, and engineering career resources for developers at every level.

Site: https://kallolchakraborty.github.io/quick-bytes/

## Tech

- [Tailwind CSS v3](https://tailwindcss.com/) — utility-first CSS (CLI build, no PostCSS)
- Vanilla JS — no framework
- [marked](https://marked.js.org/) — Markdown rendering
- [Prism](https://prismjs.com/) — syntax highlighting
- [Headroom.js](https://wicky.nillia.ms/headroom.js/) — sticky nav

## Development

```bash
npm install
npm run build   # builds css/tailwind.css
```

Open any `.html` file directly in a browser — no dev server needed.

## Deployment

GitHub Actions auto-deploys `main` to GitHub Pages. See `.github/workflows/deploy.yml`.
